Halaman ini menjelaskan cara perhitungan kuota kredit, pembatasan model per tier, multiplier statis, batas harian model gratis, serta saldo Add-on pada Neosantara Coding Plan.

## Mekanisme Kredit Rupiah

Berbeda dari paket flat berbasis jumlah hitungan prompt tetap, backend Coding Plan mengalokasikan **kredit Rupiah bulanan sebesar 1,4× harga paket**:

- **Biaya per request:** setiap request yang berhasil memotong kredit sebesar `(harga PAYG model yang diminta dalam IDR) × (multiplier statis model)`.
- **Request gagal gratis:** apabila request gagal sebelum selesai, kredit tidak dipotong.
- **Isolasi saldo PAYG:** saat batas jendela habis, request berhenti sementara (*hard-stop*) dan **tidak** memotong saldo deposit PAYG standar Anda.

## Jendela Pengeluaran

Gateway menegakkan **tiga jendela batas pengeluaran independen** dari kredit bulanan Anda, dihitung berdasarkan waktu aktivasi paket:

| Jendela | Porsi Kredit | Perilaku Reset |
| :-- | :-- | :-- |
| **Rolling 5 Jam** | Maks 20% dari kredit bulanan | Jendela berjalan 5 jam (`5 menit` bucket), terbuka lagi saat pemakaian lama keluar dari rentang 5 jam. |
| **Rolling 7 Hari (Mingguan)** | Maks 50% dari kredit bulanan | Jendela berjalan 7 hari (`1 jam` bucket), bergerak otomatis setiap jam. |
| **Siklus 30 Hari** | 100% kredit bulanan | Reset penuh pada siklus 30 hari berikutnya setelah perpanjangan/aktivasi. |

### Batas Konkurensi In-Flight

Batas konkurensi membatasi jumlah request aktif yang diproses bersamaan oleh subagent atau beberapa sesi IDE sekaligus (`4 / 10 / 20`). Jika penuh, request baru ditolak sementara sampai request yang sedang berjalan selesai.

## Bobot Multiplier Model (Statis)

Setiap pemakaian model pada kuota paket dikalikan dengan **bobot multiplier statis** (tidak pernah berubah dinamis karena beban upstream):

| Bobot | Kriteria | Contoh Model |
| :-- | :-- | :-- |
| **1×** | Model utama & gateway standar | `claude-sonnet-4-6`, `claude-opus-4-6`, `claude-sonnet-5.5`, `claude-opus-5.5`, `gemini-3-flash`, `gemini-3.1-flash-lite`, `gemini-4-hydrogen`, `gemini-4-argon`, `gpt-6-luna`, `garda-core`, `minimax-m2.7`, `gpt-oss-120b`, `mimo-v2.6-flash-free` |
| **1.5×** | Model upstream berbayar standar | `deepseek-v4-flash`, `deepseek-v4.1-flash`, `glm-5.3-flash`, `minimax-m3`, `claude-4.5-sonnet`, `claude-4.5-opus`, `claude-4-5-haiku`, `muse-spark-1.3`, `muse-wonder-1.0`, `muse-ember-1.0`, `ernie-5.5-flash-preview-free`, `mimo-v2.5`, `mimo-v2.5-pro` |
| **1.6×** | Model berat upstream berbayar | `deepseek-v4-pro`, `kimi-k3`, `glm-5.3`, `gpt-6.1-sol` |

<Note>
  Daftar model aktif per tier dan multiplier terkininya bisa langsung dicek di [Dashboard Coding Plan](https://app.neosantara.xyz/coding-plan).
</Note>

## Limit Harian Model Gratis

Model tanpa biaya token (`input = 0`, `output = 0`, seperti `ernie-5.5-flash-preview-free` dan `mimo-v2.6-flash-free`) tidak memotong saldo kredit Rupiah, tetapi dibatasi maksimal **100 request per hari (reset 00:00 UTC)** per pengguna. Gateway menyertakan header `x-neosantara-coding-free-daily-limit` dan `x-neosantara-coding-free-daily-remaining` pada respons.

## Model Add-on & Saldo Prepaid

Model yang terdaftar sebagai **Add-on** (misalnya `gemini-4-argon` atau `claude-fable-5.1` saat diaktifkan di konfigurasi add-on) tidak masuk pemotongan kredit flat paket dan tidak bergantung pada batas 5 jam/mingguan paket. Biaya pemakaiannya dipotong langsung dari **Saldo Add-on Prepaid** (tarif PAYG model + margin 40%, minimal saldo Rp 100 sebelum request).

| Paket Top-Up Add-on | Nominal |
| :-- | :-- |
| **Starter** | Rp 50.000 |
| **Basic** | Rp 100.000 |
| **Standard** | Rp 250.000 |
| **Premium** | Rp 500.000 |

## Tips Optimalisasi Kredit

1. **Gunakan Model Hemat Token & 1× untuk Iterasi Cepat**: manfaatkan `mimo-v2.6-flash-free` (maks 100 req/hari) atau model berbiaya ringan seperti `gemini-3.1-flash-lite` / `deepseek-v4.1-flash` untuk pencarian kode dan unit test ringan.
2. **Manfaatkan Prompt Caching**: jaga prefix `system` dan definisi `tools` tetap konsisten agar token cache hit mengurangi pemotongan kredit per request.
3. **Pantau Sisa Jendela**: cek sisa kredit 5 jam, mingguan, dan 30 hari melalui [Dashboard Coding Plan](https://app.neosantara.xyz/coding-plan).
