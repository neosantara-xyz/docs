Panduan ini membantu Anda mengaktifkan Neosantara Coding Plan, membuat coding key, lalu menghubungkannya ke tool atau IDE pilihan Anda.

## Langkah Konfigurasi

<Steps>
  <Step title="Login ke Dashboard">
    Buka [Dashboard Neosantara](https://app.neosantara.xyz) dan masuk ke akun Anda.
  </Step>

  <Step title="Aktivasi Paket Langganan">
    Buka menu [Coding Plan](https://app.neosantara.xyz/coding-plan) lalu pilih salah satu tier (kredit bulanan bernilai **1,4× harga paket**):

    | Tier | Kredit 5 Jam (20%) | Kredit Mingguan (50%) | Kredit 30 Hari (100%) | Harga Bulanan |
    | :-- | :-- | :-- | :-- | :-- |
    | **Coding Hemat** | Rp 41.720 | Rp 104.300 | Rp 208.600 | Rp 149.000 |
    | **Coding Reguler** | Rp 139.720 | Rp 349.300 | Rp 698.600 | Rp 499.000 |
    | **Coding Eksklusif** | Rp 361.200 | Rp 903.000 | Rp 1.806.000 | Rp 1.290.000 |

    Selesaikan invoice Mayar untuk aktivasi paket otomatis.
  </Step>

  <Step title="Buat Coding Key">
    Setelah aktif, buat key baru di [Coding Plan](https://app.neosantara.xyz/coding-plan) atau [API Keys](https://app.neosantara.xyz/api-keys). Coding key berawalan `nsk_code_` dan otomatis diberi label `[CODE]`.

    <Warning>
      Simpan token rahasia ini segera. Nilai key penuh hanya ditampilkan satu kali saat dibuat.
    </Warning>
  </Step>

  <Step title="Pilih Tool Coding yang Didukung">
    Neosantara Coding Plan bekerja pada agent yang mendukung OpenAI Chat/Responses atau Anthropic Messages dan mengirimkan identitas client yang dikenali:

    <CardGroup cols={2}>
      <Card title="Claude Code" icon="/images/integrations/claude-code.svg">
        CLI agentic resmi Anthropic lewat protokol Anthropic Messages (`/coding/paas/anthropic`).
      </Card>
      <Card title="Codex CLI & Cline" icon="/images/integrations/cline.svg">
        Codex CLI (`/coding/paas/v1` via Responses API) dan ekstensi VS Code Cline.
      </Card>
      <Card title="OpenCode, Kilo Code & Continue" icon="/images/integrations/opencode.svg">
        Agent open-source untuk terminal maupun IDE VS Code / JetBrains.
      </Card>
      <Card title="Jelma Runner" icon="cpu">
        CLI runner bawaan Neosantara yang otomatis mengatur base URL dan API key.
      </Card>
    </CardGroup>
  </Step>

  <Step title="Gunakan Base URL Kanonik">
    Arahkan konfigurasi tool ke endpoint kanonik coding berikut:

    | Protokol | Base URL Kanonik |
    | :-- | :-- |
    | Anthropic Messages | `https://api.neosantara.xyz/coding/paas/anthropic` |
    | OpenAI Chat & Responses | `https://api.neosantara.xyz/coding/paas/v1` |

    <Warning>
      Memakai endpoint PAYG biasa (`/v1` atau `/anthropic`) dengan coding key menghasilkan error `403 coding_key_requires_coding_endpoint`. Request dari HTTP client generik seperti `curl` atau SDK polos ditolak dengan `403 coding_client_not_supported`.
    </Warning>
  </Step>
</Steps>

## Contoh Konfigurasi Cepat

### Claude Code

Edit `~/.claude/settings.json` (gunakan model yang masuk tier Anda, misalnya `deepseek-v4.1-flash` yang tersedia di semua tier):

```json JSON icon="file-code"
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.neosantara.xyz/coding/paas/anthropic",
    "ANTHROPIC_API_KEY": "nsk_code_KEY_ANDA",
    "ANTHROPIC_MODEL": "deepseek-v4.1-flash",
    "ANTHROPIC_SMALL_FAST_MODEL": "deepseek-v4.1-flash",
    "API_TIMEOUT_MS": "3600000"
  }
}
```

### Cline (VS Code)

1. Buka pengaturan [Cline](https://cline.bot/?utm_source=neosantara-docs&utm_medium=referral) di VS Code.
2. Atur **API Provider** ke `OpenAI Compatible`.
3. Isi konfigurasi berikut:
   - **Base URL**: `https://api.neosantara.xyz/coding/paas/v1`
   - **API Key**: `nsk_code_KEY_ANDA`
   - **Model**: `deepseek-v4.1-flash` (atau `claude-sonnet-4-6` di tier Reguler / Eksklusif)
4. Matikan **Support Images** bila model yang dipilih hanya mendukung teks.

Untuk panduan Codex CLI, OpenCode, Kilo Code, Continue, Aider, dan Cursor, lihat [Integrasi Tool Coding](/id/coding-plan/tool-integration).

## Verifikasi Sambungan

Uji dengan satu tugas koding di dalam agent Anda:

```text Terminal icon="terminal"
Buatkan fungsi TypeScript untuk memvalidasi nomor telepon Indonesia (format +62 atau 08).
```

Jika agent merespons dan pemakaian kredit terlihat di [Dashboard Coding Plan](https://app.neosantara.xyz/coding-plan), integrasi Anda sudah aktif.
