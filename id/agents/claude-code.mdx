Claude Code adalah asisten koding berbasis terminal resmi dari Anthropic. Anda dapat menggunakannya bersama Neosantara melalui dua cara: sebagai penyedia model LLM utama atau sebagai penyedia tools tambahan melalui Model Context Protocol (MCP).

## Metode 1: Penyedia Model Utama

Neosantara menyediakan endpoint yang kompatibel dengan protokol Anthropic di `/anthropic`.

<Steps>
  <Step title="Pasang Claude Code CLI">
```bash
npm install -g @anthropic-ai/claude-code
```
  </Step>

  <Step title="Konfigurasikan Variabel Lingkungan">
Atur base URL ke gateway Neosantara dan masukkan API key Anda:

```bash
export ANTHROPIC_BASE_URL="https://api.neosantara.xyz/anthropic"
export ANTHROPIC_API_KEY="nsk_your_api_key_here"
```

Untuk persistensi di sesi terminal berikutnya, tambahkan baris di atas ke file konfigurasi shell Anda (`~/.bashrc` atau `~/.zshrc`).
  </Step>

  <Step title="Jalankan Claude Code">
Masuk ke direktori proyek Anda dan jalankan perintah:

```bash
claude
```

Claude Code akan langsung terhubung ke Neosantara menggunakan model default `claude-sonnet-4-6`.
  </Step>
</Steps>

## Metode 2: Menambahkan Server MCP Neosantara

Jika Anda ingin Claude Code mengakses tools Neosantara seperti pembuatan gambar atau katalog model aktif, tambahkan Neosantara sebagai server MCP:

```bash
claude mcp add --transport http neosantara https://api.neosantara.xyz/v1/mcp --header "x-api-key: nsk_mcp_your_key_here"
```

<Note>
Koneksi MCP membutuhkan API key khusus berawalan `nsk_mcp_`. Dapatkan API key ini melalui [Dashboard API Keys](https://app.neosantara.xyz/api-keys) atau panduan [API Key MCP](/id/agents/mcp-keys).
</Note>

### Memverifikasi Server MCP

Periksa status server MCP yang terhubung:

```bash
claude mcp list
```

Output terminal akan menampilkan `neosantara` dengan status aktif dan daftar tools yang tersedia.

## Pengujian Interaksi
