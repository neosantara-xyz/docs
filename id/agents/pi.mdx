[Pi](https://github.com/badlogic/pi-mono) (`@mariozechner/pi-coding-agent`) adalah asisten koding terminal yang dirancang sangat cepat, modular, dan efisien. Pi mendukung navigasi sesi interaktif bercabang (*tree sessions*), eksekusi bash terisolasi, manipulasi file langsung, dan ekstensi TypeScript tanpa dependensi runtime yang berat.

## Instalasi Pi

Pasang Pi secara global menggunakan Node.js dan npm:

```bash
npm install -g @mariozechner/pi-coding-agent
```

## Konfigurasi Gateway Neosantara

### Opsi A: Variabel Lingkungan

Cara tercepat menghubungkan Pi adalah dengan mengekspor konfigurasi OpenAI-compatible ke gateway Neosantara:

```bash
export OPENAI_BASE_URL="https://api.neosantara.xyz/v1"
export OPENAI_API_KEY="nsk_your_api_key_here"
```

### Opsi B: File Konfigurasi Global

Anda juga dapat menyimpan pengaturan default pada `~/.pi/config.json`:

```json
{
  "provider": "openai",
  "baseURL": "https://api.neosantara.xyz/v1",
  "apiKey": "nsk_your_api_key_here",
  "model": "deepseek-v4.1-flash"
}
```

## Menjalankan Pi

Buka repositori proyek Anda di terminal, lalu jalankan perintah `pi`:

```bash
pi
```

Atau tentukan model dan provider langsung melalui argumen CLI:

```bash
pi --provider openai --model deepseek-v4.1-flash
```

Contoh instruksi koding interaktif:

```text
> Temukan seluruh penggunaan console.log yang tidak terproteksi di src/ dan ganti dengan logger terstruktur.
```

Pi akan membaca file, menganalisis struktur kode, menampilkan diff perubahan, dan meminta konfirmasi sebelum menerapkan modifikasi ke disk.
