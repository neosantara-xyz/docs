Endpoint `/v1/images/generations` menyediakan paritas penuh dengan OpenAI Images API untuk menghasilkan gambar dari prompt teks.

<CodeGroup>

```python Python (OpenAI SDK) icon="python"
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://api.neosantara.xyz/v1",
    api_key=os.environ["NEOSANTARA_API_KEY"]
)

response = client.images.generate(
    model="imagen-4.0-fast",
    prompt="Pemandangan sawah terasering di Ubud Bali saat matahari terbit, fotorealistik.",
    size="1024x1024",
    n=1
)

image_url = response.data[0].url
print(f"URL Gambar: {image_url}")
```

```javascript Node.js (OpenAI SDK) icon="js"
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.neosantara.xyz/v1",
  apiKey: process.env.NEOSANTARA_API_KEY,
});

const response = await client.images.generate({
  model: "imagen-4.0-fast",
  prompt: "Pemandangan sawah terasering di Ubud Bali saat matahari terbit, fotorealistik.",
  size: "1024x1024",
  n: 1,
});

console.log("URL Gambar:", response.data[0].url);
```

```bash cURL icon="terminal"
curl -X POST https://api.neosantara.xyz/v1/images/generations \
  -H "Authorization: Bearer $NEOSANTARA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "imagen-4.0-fast",
    "prompt": "Pemandangan sawah terasering di Ubud Bali.",
    "size": "1024x1024",
    "n": 1
  }'
```

</CodeGroup>

## Parameter Permintaan

| Parameter | Tipe | Wajib | Keterangan |
| :-- | :-- | :-- | :-- |
| `prompt` | `string` | Ya | Deskripsi teks visual gambar yang ingin dibuat. |
| `model` | `string` | Ya | Pengidentifikasi model (contoh: `imagen-4.0-fast`, `titan-image-g1`). |
| `size` | `string` | Opsional | Dimensi gambar (contoh: `1024x1024`, `512x512`). Default `1024x1024`. |
| `n` | `integer` | Opsional | Jumlah variasi gambar yang dihasilkan (1 sampai 4). Default `1`. |
| `response_format` | `string` | Opsional | Format keluaran: `"url"` atau `"b64_json"`. Default `"url"`. |

## Arsitektur Teknis & Caching

- **Sinkron vs Asinkron**: Endpoint standar `/v1/images/generations` dirancang untuk integrasi langsung waktu nyata. Untuk proses batch atau model resolusi tinggi, gunakan [Responses API](/id/gateway/responses-api) dengan parameter `background: true` untuk menghindari HTTP timeout.
- **CDN Ephemeral & TTL Caching**: Gambar yang dihasilkan disajikan melalui CDN berkecepatan tinggi dengan URL bertanda tangan sementara. Tautan berlaku selama **5 menit** (TTL). Unduh gambar ke storage permanen (S3/GCS/R2) jika membutuhkan retensi jangka panjang.
- **Perlindungan SSRF**: Saat menyediakan URL gambar input untuk tugas manipulasi/inpainting, gateway memvalidasi rentang IP publik dan memblokir alamat loopback serta jaringan privat untuk mencegah *Server-Side Request Forgery* (SSRF).
- **Penagihan Rupiah**: Biaya generasi gambar dihitung per unit gambar yang berhasil dibuat (_per-image pricing_), bukan berdasarkan token. Biaya langsung didebet dari saldo deposit Rupiah Anda.
