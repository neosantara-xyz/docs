This guide covers activating the Neosantara Coding Plan, generating a coding key, and connecting supported coding clients.

## Configuration Steps

<Steps>
  <Step title="Sign In to Dashboard">
    Visit the [Neosantara Dashboard](https://app.neosantara.xyz) and sign in to your account.
  </Step>

  <Step title="Activate a Plan or Claim Trial">
    Open [Coding Plan](https://app.neosantara.xyz/coding-plan) and pick a tier (monthly credit equals **1.4× the subscription price**):

    | Tier | 5-Hour Cap (20%) | Weekly Cap (50%) | 30-Day Credit (100%) | Monthly Price |
    | :-- | :-- | :-- | :-- | :-- |
    | **Coding Hemat** | IDR 41,720 | IDR 104,300 | IDR 208,600 | IDR 149,000 |
    | **Coding Reguler** | IDR 139,720 | IDR 349,300 | IDR 698,600 | IDR 499,000 |
    | **Coding Eksklusif** | IDR 361,200 | IDR 903,000 | IDR 1,806,000 | IDR 1,290,000 |

    Pay the Mayar invoice for activation. Eligible accounts can also claim a one-time **3-Day Free Trial** on Coding Hemat with **IDR 25,000** in coding credit from the [Coding Plan Dashboard](https://app.neosantara.xyz/coding-plan).
  </Step>

  <Step title="Generate a Coding Key">
    Once active, generate a coding key on [Coding Plan](https://app.neosantara.xyz/coding-plan) or [API Keys](https://app.neosantara.xyz/api-keys). Keys start with `nsk_code_` and use the `[CODE]` name prefix.

    <Warning>
      Save your key immediately. The raw secret is shown only once at creation.
    </Warning>
  </Step>

  <Step title="Connect a Supported Coding Tool">
    Neosantara Coding Plan works with coding agents using OpenAI Chat/Responses or Anthropic Messages formats that identify themselves as supported clients:

    <CardGroup cols={2}>
      <Card title="Claude Code" icon="/images/integrations/claude-code.svg">
        Anthropic's agentic CLI via Anthropic Messages (`/coding/paas/anthropic`).
      </Card>
      <Card title="Codex CLI & Cline" icon="/images/integrations/cline.svg">
        Codex CLI (`/coding/paas/v1` Responses API) and Cline for VS Code.
      </Card>
      <Card title="OpenCode, Kilo Code & Continue" icon="/images/integrations/opencode.svg">
        Open-source coding agents for terminal, VS Code, and JetBrains IDEs.
      </Card>
      <Card title="Jelma Runner" icon="cpu">
        Neosantara's CLI runner that injects base URLs and credentials automatically.
      </Card>
    </CardGroup>
  </Step>

  <Step title="Select Canonical Base URLs">
    Configure your client with the canonical coding base URLs:

    | Protocol | Canonical Base URL |
    | :-- | :-- |
    | Anthropic Messages | `https://api.neosantara.xyz/coding/paas/anthropic` |
    | OpenAI Chat & Responses | `https://api.neosantara.xyz/coding/paas/v1` |

    <Warning>
      Sending a coding key to standard PAYG endpoints (`/v1` or `/anthropic`) fails with `403 coding_key_requires_coding_endpoint`. Calls from generic HTTP clients such as `curl` or raw SDKs fail with `403 coding_client_not_supported`.
    </Warning>
  </Step>
</Steps>

## Quick Setup Examples

### Claude Code

Edit `~/.claude/settings.json` (choose a model permitted in your tier, such as `deepseek-v4.1-flash`, which works across Hemat, Trial, Reguler, and Eksklusif):

```json JSON icon="file-code"
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.neosantara.xyz/coding/paas/anthropic",
    "ANTHROPIC_API_KEY": "nsk_code_YOUR_KEY",
    "ANTHROPIC_MODEL": "deepseek-v4.1-flash",
    "ANTHROPIC_SMALL_FAST_MODEL": "deepseek-v4.1-flash",
    "API_TIMEOUT_MS": "3600000"
  }
}
```

### Cline (VS Code)

1. Open Cline settings in VS Code.
2. Set **API Provider** to `OpenAI Compatible`.
3. Configure the following fields:
   - **Base URL**: `https://api.neosantara.xyz/coding/paas/v1`
   - **API Key**: `nsk_code_YOUR_KEY`
   - **Model**: `deepseek-v4.1-flash` (or `claude-sonnet-4-6` on Reguler / Eksklusif)
4. Disable **Support Images** when using text-only models.

For Codex CLI, OpenCode, Kilo Code, Continue, Aider, and Cursor configs, see [Tool Integration](/en/coding-plan/tool-integration).

## Verify Connection

Send a quick coding prompt inside your agent:

```text Terminal icon="terminal"
Write a TypeScript function to validate Indonesian phone numbers (+62 or 08 prefix).
```

When the agent responds and your credit usage updates on the [Coding Plan Dashboard](https://app.neosantara.xyz/coding-plan), the setup is working.
