Neosantara Coding Plan works with supported coding tools that speak **OpenAI Chat Completions**, **OpenAI Responses**, or **Anthropic Messages**.

## Supported Tools

<CardGroup cols={2}>
  <Card title="Claude Code" icon="/images/integrations/claude-code.svg">
    Anthropic's agentic CLI using the Anthropic Messages endpoint (`/coding/paas/anthropic`).
  </Card>
  <Card title="Codex CLI" icon="terminal">
    OpenAI's official coding CLI (`@openai/codex`) using the OpenAI Responses protocol (`wire_api = "responses"`).
  </Card>
  <Card title="OpenCode & Kilo Code" icon="/images/integrations/opencode.svg">
    Open-source terminal coding agents (`opencode`, `kilo`) using the OpenAI-compatible endpoint.
  </Card>

    CLIs and IDE extensions connecting through `/coding/paas/v1`.
  </Card>
</CardGroup>

## Coding Endpoints

| Protocol | Canonical Base URL | Tools |
| :-- | :-- | :-- |
| **Anthropic Messages** | `https://api.neosantara.xyz/coding/paas/anthropic` | Claude Code |
| **OpenAI Chat & Responses** | `https://api.neosantara.xyz/coding/paas/v1` | Codex CLI, OpenCode, Kilo Code, Cline, Roo Code, Aider, Continue, Cursor |

<Warning>
  Coding keys (`nsk_code_*`) are only accepted on `/coding/paas/*` endpoints and only from recognized coding tools. Calling standard PAYG endpoints (`/v1` or `/anthropic`) or using a generic HTTP client (`curl`, raw SDK) returns `403`.
</Warning>

## Per-Tool Configuration

### 1. Claude Code

Edit `~/.claude/settings.json` (or export as environment variables):

```json JSON icon="file-code"
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.neosantara.xyz/coding/paas/anthropic",
    "ANTHROPIC_API_KEY": "nsk_code_YOUR_KEY",
    "ANTHROPIC_MODEL": "deepseek-v4.1-flash",
    "ANTHROPIC_SMALL_FAST_MODEL": "deepseek-v4.1-flash",
    "API_TIMEOUT_MS": "3600000"
  }
}
```

### 2. Codex CLI (`@openai/codex`)

Codex CLI requires `wire_api = "responses"` in `~/.codex/config.toml`:

```toml TOML icon="file-code"
model = "deepseek-v4.1-flash"
model_provider = "neosantara"

[model_providers.neosantara]
name = "Neosantara Coding Gateway"
base_url = "https://api.neosantara.xyz/coding/paas/v1"
wire_api = "responses"
env_key = "CODEX_API_KEY"
```

```bash Terminal icon="terminal"
export CODEX_API_KEY="nsk_code_YOUR_KEY"
codex exec "Add unit tests for the auth module"
```

### 3. OpenCode CLI (`opencode`)

Create `~/.config/opencode/opencode.json`:

```json JSON icon="file-code"
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "neosantara": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Neosantara Coding Gateway",
      "options": {
        "baseURL": "https://api.neosantara.xyz/coding/paas/v1",
        "apiKey": "{env:NEOSANTARA_API_KEY}"
      },
      "models": {
        "deepseek-v4.1-flash": {
          "name": "DeepSeek V4.1 Flash",
          "limit": { "context": 128000, "output": 8192 }
        }
      }
    }
  }
}
```

```bash Terminal icon="terminal"
export NEOSANTARA_API_KEY="nsk_code_YOUR_KEY"
opencode run -m neosantara/deepseek-v4.1-flash "Explain this project layout"
```

### 4. Kilo Code CLI (`@kilocode/cli`)

Create `~/.config/kilo/kilo.jsonc`:

```json JSON icon="file-code"
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "neosantara/deepseek-v4.1-flash",
  "provider": {
    "neosantara": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Neosantara Coding Gateway",
      "options": {
        "baseURL": "https://api.neosantara.xyz/coding/paas/v1",
        "apiKey": "{env:NEOSANTARA_API_KEY}"
      },
      "models": {
        "deepseek-v4.1-flash": {
          "name": "DeepSeek V4.1 Flash",
          "tool_call": true,
          "limit": { "context": 128000, "output": 8192 }
        }
      }
    }
  }
}
```

### 5. Continue CLI (`@continuedev/cli` / `cn`)

In CLI mode (`provider: openai`), the underlying OpenAI JS SDK sends a generic `User-Agent` (`ls/JS ...`). Add `x-continue-unique-id` under `requestOptions.headers` in `~/.continue/config.yaml` so the Coding Plan guard recognizes it:

```yaml YAML icon="file-code"
name: Neosantara Coding Plan
version: 1.0.0
schema: v1
models:
  - name: DeepSeek V4.1 Flash
    provider: openai
    model: deepseek-v4.1-flash
    apiBase: https://api.neosantara.xyz/coding/paas/v1
    apiKey: nsk_code_YOUR_KEY
    requestOptions:
      headers:
        x-continue-unique-id: continue-cli
    capabilities:
      - tool_use
    roles:
      - chat
      - edit
      - apply
```

### 6. Aider (`aider-chat`)

When using the `openai/` model prefix, Aider sends the default Python SDK `User-Agent` (`OpenAI/Python ...`). Pass `extra_headers` via `.aider.model.settings.yml`:

```yaml YAML icon="file-code"
- name: openai/deepseek-v4.1-flash
  edit_format: whole
  extra_params:
    extra_headers:
      User-Agent: aider/0.86.2
```

```bash Terminal icon="terminal"
export OPENAI_API_BASE="https://api.neosantara.xyz/coding/paas/v1"
export OPENAI_API_KEY="nsk_code_YOUR_KEY"
aider --model openai/deepseek-v4.1-flash --model-settings-file .aider.model.settings.yml
```

### 7. Cline, Roo Code (VS Code) & Cursor

Set **API Provider** to `OpenAI Compatible` (Cline / Roo Code) or **Add Custom Model** (Cursor):

- **Base URL**: `https://api.neosantara.xyz/coding/paas/v1`
- **API Key**: `nsk_code_YOUR_KEY`
- **Model ID**: any model allowed on your Coding Plan tier (for example `deepseek-v4.1-flash` or `claude-sonnet-4-6`).

### 8. Jelma CLI Runner (Automatic)

```bash Terminal icon="terminal"
jelma claude local
jelma opencode local
```

Jelma automatically loads your Coding Plan key and injects the right base URL.
