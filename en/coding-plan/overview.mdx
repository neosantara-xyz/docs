**Neosantara Coding Plan** is a flat-fee subscription designed for AI-assisted coding workflows, granting a monthly **Rupiah credit pool equal to 1.4× the plan price**. It works with Claude Code, Codex CLI, OpenCode, Kilo Code, Cline, Continue, Cursor, Aider, and Jelma.

<Note>
  Coding keys (`nsk_code_*`) only work on dedicated coding URLs (**`/coding/paas/v1`** and **`/coding/paas/anthropic`**) and only from recognized coding tools. Sending a coding key to standard PAYG endpoints (`/v1` or `/anthropic`) fails with HTTP `403`. Standard PAYG keys sent to coding URLs are billed from your regular PAYG balance and do not touch Coding Plan credits.
</Note>

## How It Works

| Concept | Detail |
| :-- | :-- |
| **Rupiah Credit Pool (1.4×)** | Every plan provides monthly coding credit equal to 1.4× the subscription price for a 30-day cycle. |
| **Credit Deduction** | Completed requests deduct the PAYG list cost of the requested model scaled by that model's static multiplier. Failed requests cost Rp 0. |
| **Three Spend Windows** | Independent rolling 5-hour (20%), rolling 7-day (50%), and 30-day cycle (100%) spending caps. |
| **Hard-Stop, Zero Overage** | When any window is depleted, requests pause with an error until the next reset. Your PAYG balance is never charged automatically. |
| **3-Day Free Trial** | One-time 3-day trial on Coding Hemat with IDR 25,000 in coding credit via the [Coding Plan Dashboard](https://app.neosantara.xyz/coding-plan). |
| **Renewal** | One-time 30-day invoice without auto-renewal. Reminder emails are sent 3 days before expiry. |

## Dedicated Base URLs

Coding keys (`nsk_code_*`) are accepted on the canonical coding endpoints below:

| Protocol | Canonical Base URL |
| :-- | :-- |
| OpenAI Chat & Responses | `https://api.neosantara.xyz/coding/paas/v1` |
| Anthropic Messages | `https://api.neosantara.xyz/coding/paas/anthropic` |

<Warning>
  Legacy `/coding/v1` and `/coding/anthropic` paths are deprecated and return a `Warning: 299` header. Sending coding keys to regular endpoints (`/v1` or `/anthropic`) returns `403 coding_key_requires_coding_endpoint`.
</Warning>

## Quick Start Steps

<Steps>
  <Step title="Activate a Plan or Trial">
    Open the [Coding Plan Dashboard](https://app.neosantara.xyz/coding-plan), select **Hemat**, **Reguler**, or **Eksklusif**, and complete payment via Mayar (or claim your one-time 3-day IDR 25,000 trial).
  </Step>
  <Step title="Create a Coding Key">
    Once active, create a key on [Coding Plan](https://app.neosantara.xyz/coding-plan) or [API Keys](https://app.neosantara.xyz/api-keys). Coding keys start with `nsk_code_` and carry the `[CODE]` name prefix.
  </Step>
  <Step title="Configure Your Tool">
    Point your coding client to the canonical `/coding/paas/*` base URLs with your coding key.

    **Claude Code** (`~/.claude/settings.json`):
    ```json JSON icon="file-code"
    {
      "env": {
        "ANTHROPIC_BASE_URL": "https://api.neosantara.xyz/coding/paas/anthropic",
        "ANTHROPIC_API_KEY": "nsk_code_YOUR_KEY",
        "ANTHROPIC_MODEL": "deepseek-v4.1-flash"
      }
    }
    ```

    **Cline / OpenCode / Continue** (OpenAI mode):
    ```text Terminal icon="terminal"
    Base URL: https://api.neosantara.xyz/coding/paas/v1
    API Key:  nsk_code_YOUR_KEY
    Model:    deepseek-v4.1-flash
    ```
  </Step>
  <Step title="Or Launch via Jelma">
    Use the [Jelma](https://app.neosantara.xyz/jelma) CLI to launch local agents without editing config files (`jelma claude local`, `jelma opencode local`).
  </Step>
</Steps>

## Quotas, Multipliers, and Add-ons

Each subscription tier sets its own model allowlist (`Hemat`, `Reguler`, `Eksklusif`), concurrent in-flight limit, static credit multipliers (`1×`, `1.5×`, `1.6×`), and optional prepaid Add-on credit support for premium add-on models.

For exact tier credit budgets and window rules, see [Quotas & Limits](/en/coding-plan/quota-and-limits).

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Does the Coding Plan renew automatically?">
    No. Invoices cover one 30-day billing cycle at a time. The platform sends renewal reminder emails 3 days before expiration.
  </Accordion>
  <Accordion title="What happens when credit in a window is exhausted?">
    Requests hard-stop until the 5-hour, 7-day, or 30-day window resets. Your standard PAYG deposit balance is never deducted.
  </Accordion>
  <Accordion title="Can I use a coding key on /v1 or from plain curl?">
    No. Coding keys only work on `/coding/paas/v1` and `/coding/paas/anthropic` from recognized coding clients (Claude Code, Codex CLI, OpenCode, Cline, Cursor, Continue, Aider, Windsurf, Kilo Code, etc.). Raw `curl` or plain SDK calls return `403 coding_client_not_supported`.
  </Accordion>
  <Accordion title="Which models can I access?">
    You can call every model in your tier allowlist, plus designated add-on models when you hold at least IDR 100 in your prepaid Add-on balance.
  </Accordion>
</AccordionGroup>
