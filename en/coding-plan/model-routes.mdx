**Model Routes** lets Coding Plan subscribers define virtual model aliases that map to an ordered fallback chain of real catalog models. When the primary model encounters upstream capacity errors or rate limits, the gateway fails over automatically to the next model in the chain.

<Note>
  Model Routes requires an **active Coding Plan subscription** and must be called with a coding key (`nsk_code_*`) through `/coding/paas/v1` or `/coding/paas/anthropic`.
</Note>

## How It Works

```text
Virtual Name: my-coder
       │
       ▼
1. Primary Model: claude-4.5-sonnet
       │ (on capacity error)
       ▼
2. Fallback Model: deepseek-v4.1-flash
```

1. You define a virtual alias (such as `my-coder`) in the [Coding Plan Dashboard](https://app.neosantara.xyz/coding-plan) with an ordered list of models (`["claude-4.5-sonnet", "deepseek-v4.1-flash"]`).
2. Sending requests with `model: "my-coder"` to coding endpoints executes the first model in the chain.
3. If the primary model fails due to upstream capacity limits, the gateway dispatches the request to the next model in your chain.

## Tier Limits

| Subscription Tier | Max Models Per Chain | Max Routes Per Account |
| :-- | :-- | :-- |
| **Coding Hemat** | 3 models | 3 routes |
| **Coding Reguler** | 5 models | 10 routes |
| **Coding Eksklusif** | 8 models | 25 routes |

## Route Creation Rules

- Virtual route names cannot collide with existing catalog model IDs or aliases (for example, you cannot name a route `claude-4.5-sonnet`).
- Route names are case-insensitive and unique per account.
- Every model in the chain must be permitted for your active Coding Plan tier (or enabled via add-on models).
- Route names allow up to 100 characters matching `^[a-zA-Z0-9][a-zA-Z0-9._:/-]*$`.

## Using Virtual Routes in Clients

Once configured, supply the virtual alias as your model ID:

### 1. Jelma CLI

```bash Terminal icon="terminal"
jelma claude local --model my-coder
jelma opencode local --model my-coder
```

### 2. Claude Code

Edit `~/.claude/settings.json`:

```json JSON icon="file-code"
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.neosantara.xyz/coding/paas/anthropic",
    "ANTHROPIC_API_KEY": "nsk_code_YOUR_KEY",
    "ANTHROPIC_MODEL": "my-coder"
  }
}
```

### 3. Cline / OpenCode

Enter the virtual route name in your model setting (with Base URL set to `https://api.neosantara.xyz/coding/paas/v1`):

```text Configuration icon="terminal"
Model: my-coder
```
