  <Step title="Set Your API Key">
    Retrieve your API key from the [Neosantara Dashboard](https://app.neosantara.xyz/api-keys) and set it in your environment:

    <SetApiKey />
  </Step>

  <Step title="Initialize the Client">
    Configure the OpenAI or Anthropic SDK to target the Neosantara base URL:

    <BaseUrlConfig />
  </Step>

  <Step title="Make a Request">
    Dispatch your first inference request to our high-speed flagship reasoning model:

```python
response = client.chat.completions.create(
    model="deepseek-v4.1-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain Indonesia's AI Gateway in one sentence."}
    ]
)

print(response.choices[0].message.content)
```
  </Step>
</Steps>
