## Use These Docs with Coding Agents

Add Neosantara documentation directly to your AI coding agents (such as Claude Code, Cursor, Windsurf, or OpenCode) using a single command:

```bash Terminal icon="terminal"
npx skills add https://docs.neosantara.xyz
```

This installs the official Neosantara documentation skill automatically, allowing your coding agent to retrieve API endpoints, model catalogs, and integration patterns on the fly.
